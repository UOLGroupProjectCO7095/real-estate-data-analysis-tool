## PERT and Critical Path Analysis
## Project Details
## Project Name: CO7095 – Real Estate Data Collection and Analysis Tool
## Introduction

This folder contains the PERT chart and critical path analysis for our project. We used PERT to plan the activities involved in developing the system and to show how the different tasks depend on each other.

The analysis helps us understand which activities need to be completed first, how much time the project may take and which tasks could affect the overall completion date.

## Files in This Folder

File	Description
PERT_Activities.csv	Contains the project activities, their dependencies and estimated completion times.
PERT_Analysis.md	Explains the PERT method and the project schedule.
PERT_Diagram.png	Shows the project activities and how they are connected.

## Project Timeline

* Project Start Date: 23 November 2026
* Final Submission Date: 4 January 2027
* Number of Sprints: 3
* Sprint Duration: 2 weeks

## Purpose of the Analysis

The main purpose of this analysis is to plan the project in a clear order and identify the critical path. This helps our team understand which activities are important for completing the project on time and where delays could affect other tasks.

The activity estimates and dependencies are used to prepare the PERT diagram and carry out the critical path analysis.
